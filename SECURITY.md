# Security policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use **Report a vulnerability** in the
repository Security tab to open a private GitHub advisory. Include affected versions, impact,
reproduction steps, and potential mitigations. An acknowledgement should arrive within seven days;
disclosure timing will be coordinated after a fix is understood.

Do not submit real credentials, personal data, or destructive payloads.
